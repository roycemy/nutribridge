# NutriBridge

A polished, front-end first prototype for a US dietary supplement sourcing operation serving medical clinics and wellness practices.

## Included in this first slice

- Supplier and clinic CRM with relationship history, preferences and value
- DSHEA-limited product catalog with structure/function claim review
- Lot-level batch traceability, inventory, expiry and CoA status
- Sales, gross margin and operations dashboard with realistic demo data
- Draft-and-review outreach queue with CAN-SPAM release gates
- Compliance workspace that blocks disease treatment, cure and prevention claims

## Guardrails

This prototype is scoped to dietary supplements and dietary ingredients, not pharmaceuticals, peptides or unapproved drugs. It does not provide legal advice. Real operations still require qualified regulatory counsel, truthful labeling, substantiated claims, supplier qualification, current quality records and all applicable federal and state requirements.

Outreach is intentionally a review queue. This version does not scrape contacts or send messages.

## Run locally

Open `index.html` in a browser. No build step or environment variables are required.
